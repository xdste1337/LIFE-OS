# LIFE OS

Адаптивный интерфейс персонального пространства для задач, календаря, заметок, финансов и целей.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Демоданные и записи пока сохраняются в локальном хранилище текущего браузера.

## Что доступно в прототипе

- Обзор дня с задачами, событиями, привычками, целями и заметками.
- Календарь с переходом между месяцами, выбором даты и управлением событиями на конкретный день.
- Финансовые сводки по валютам с фильтром периода, общий и категорийные месячные бюджеты, импорт CSV с датой и валютой в отдельных колонках.
- Добавление задач, событий, заметок, проектов, привычек, целей, финансовых операций и входящих записей.
- Отметка задач, количественный прогресс привычек, сортировка задач по статусу, поиск заметок.
- Разделы финансов, аналитики, календаря и персональных настроек.
- Светлая, тёмная и фиолетовая темы, адаптация для мобильных экранов, экспорт данных в JSON.
- Регистрация и вход по email через Supabase Auth.

## Текущий этап

Вход по email подключён к Supabase Auth. Данные LIFE OS пока сохраняются только в локальном хранилище браузера; облачная синхронизация модулей ещё не включена.

## Основа для личных и общих пространств

`supabase/migrations/20261109000100_workspaces_and_life_data.sql` задаёт структуру профилей, личных пространств, общих пространств, участников с ролями Owner/Admin/Editor/Viewer и приглашений. Данные модулей привязаны к пространству и защищены RLS. Новому аккаунту автоматически создаётся личное пространство; общее пространство создаётся отдельно, а участники добавляются только по приглашению.

Миграция `20261109000100_workspaces_and_life_data.sql` успешно применена в SQL Editor. Перед подключением браузерного клиента к таблицам LIFE OS также нужно применить `20261109000200_api_grants_and_function_privileges.sql`. Открой файл, скопируй весь SQL в Supabase → SQL Editor → New query и нажми Run. Для статической версии публичные настройки Supabase находятся в `supabase/config.js`; publishable key предназначен для браузера и не даёт обходить RLS.

Чтобы включить подтверждение регистрации по email на опубликованном сайте, в Supabase укажи `https://xdste1337.github.io/LIFE-OS/` как Site URL и добавь этот же адрес в список Redirect URLs.
