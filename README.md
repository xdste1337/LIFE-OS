# LIFE OS

Адаптивный интерфейс персонального пространства для задач, календаря, заметок, финансов и целей.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Все изменения сохраняются в локальном хранилище текущего браузера.

## Что доступно в прототипе

- Обзор дня с задачами, событиями, привычками, целями и заметками.
- Календарь с переходом между месяцами, выбором даты и управлением событиями на конкретный день.
- Финансовые сводки по валютам с фильтром периода, общий и категорийные месячные бюджеты, импорт CSV с датой и валютой в отдельных колонках.
- Добавление задач, событий, заметок, проектов, привычек, целей, финансовых операций и входящих записей.
- Отметка задач, количественный прогресс привычек, сортировка задач по статусу, поиск заметок.
- Разделы финансов, аналитики, календаря и персональных настроек.
- Светлая, тёмная и фиолетовая темы, адаптация для мобильных экранов, экспорт данных в JSON.

## Следующий этап

Это стартовый интерфейсный прототип. Для регистрации и входа, совместной работы, синхронизации между устройствами и Telegram Mini App потребуется подключить backend и Supabase Auth/PostgreSQL с политиками RLS. Сейчас демонстрационные данные и новые записи хранятся только в браузере.
